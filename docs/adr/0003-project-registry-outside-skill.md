# 项目登记表移出技能文件，改存 deploy-kit\projects.md

## Status

accepted

部署流程要登记每个项目的源根、基线清单、输出目录、部署物构成与最近部署记录。这些数据含
真实项目名与真实路径，而 `.agents\skills\` 下的文件是本仓库（公开）的发布物——与 ADR-0001
同一条原则：「模板工具包对外发布时不能携带任何真实机器路径」。此外技能文件在本机会有两份
副本（仓库内 / 工作区内 / 用户级），注册只写其中一份必然分叉。

我们选择：登记表改存 `deploy-kit\projects.md`（本机文件，进 `.gitignore`，不随仓库发布）；
技能文件只保留表结构与登记流程说明，不承载任何项目数据。

被否方案：

- 继续写进 SKILL.md——发布即带真实项目信息，且技能副本之间会分叉；
- 每个项目一份配置文件——没有总览，「最近部署」的检索与维护更麻烦。

## Consequences

- 项目注册完成 = 基线清单落 `deploy-kit\maps\` + 登记行落 `deploy-kit\projects.md`；
- `.gitignore` 忽略 `projects.md`，并收窄 `maps\` 只允许虚构样例入库；
- 技能文件可安全公开；项目数据只在本机。
